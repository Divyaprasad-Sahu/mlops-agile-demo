# Iris dataset

The project uses the 150-row Iris dataset bundled with scikit-learn; no network
download is needed at training time. `iris.csv` is an exported copy for inspection.
Four features, in centimetres: sepal length, sepal width, petal length, petal width.
Targets: setosa, versicolor, virginica (50 examples each).

Source: scikit-learn `load_iris`, based on Fisher's Iris dataset.
